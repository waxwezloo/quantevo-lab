Терминал для **эволюционной оптимизации торговой стратегии** на данных Bybit и **торговли реальными активами** (paper / live) прямо из браузера. Стратегия **FibDiv** сочетает зоны ретрейсмента Фибоначчи, RSI-дивергенции, трендовый фильтр EMA и импульс по **методу Такенса (delay-embedding) со сглаживанием расширенным фильтром Калмана (EKF)**. Генетический алгоритм подбирает 15 генов стратегии под выбранную пару и таймфрейм.

## Возможности

### Веб-терминал (React + TypeScript, без бэкенда)

- **40 торговых пар Bybit** (BTC, ETH, SOL, BNB, XRP … PEPE, SHIB) — spot и USDT Perpetual;
- **12 таймфреймов**: 1м, 3м, 5м, 15м, 30м, **1Ч, 4Ч** (основные), 6Ч, 12Ч, 1Д, 1Н; глубина до 365 дней;
- **Стратегия FibDiv**: вход в Фибо-зоне ретрейсмента при подтверждённой RSI-дивергенции, Такенс-импульсе (EKF) и трендовом EMA-фильтре;
- **Генетический алгоритм**: популяция 20–120, до 80 поколений, турнирный отбор, BLX-кроссовер, гауссова мутация, элитизм, фиксируемый сид;
- **Фитнес-функция** с настраиваемыми весами: `Sharpe + Profit Factor + доходность − штраф за просадку`;
- **Честный бэктест**: исполнение по open следующего бара, TP/SL внутри бара, комиссия taker, проскальзывание, реверс-выход, **плечо ×1–25, фандинг, модель ликвидации**;
- **Риск/награда**: сетап (TP/SL из генома) и реализованный (ср. прибыль / ср. убыток);
- **Экспорт/импорт генома** в JSON — совместим с `best_params.json` Python-скрипта;
- **Вкладка «Торговля · Live»**: paper- и live-исполнение, API-ключи Bybit (подпись HMAC локально, Web Crypto), начальный депозит, риск на сделку 0.1–5%, **линии SL/TP/входа на живом графике**, карточка позиции, журнал сделок и движка, мониторинг баланса;
- **Вкладка «Python-код»**: полный автономный скрипт с подсветкой синтаксиса и кнопкой скачивания — генерируется под выбранные пару/таймфрейм/режим;
- автоматический фолбэк на синтетические данные, если Bybit API недоступен из браузера (CORS/сеть).

### Python-движок (`python/ga_bybit_trader.py`)

Тот же алгоритм на NumPy: загрузка года свечей с пагинацией, векторизованные индикаторы, мультипроцессорная эволюция (`multiprocessing.Pool`), отчёт по метрикам, экспорт генома в `best_params.json`, прогон импортированного генома без GA.

Требования: **Python 3.10+**.

```bash
cp .env.example .env                                # и заполните ключи
```

### Бэктест + эволюция (по умолчанию — спот, 1Ч, 365 дней)

```bash
python ga_bybit_trader.py                                # BTCUSDT, 1Ч
python ga_bybit_trader.py --symbol ETHUSDT --interval 240          # 4Ч
python ga_bybit_trader.py --symbol SOLUSDT --pop 96 --gens 60 --seed 7
python ga_bybit_trader.py --symbol XRPUSDT --interval 1440 --days 365  # 1Д
```

### Перпетуал с плечом

```bash
python ga_bybit_trader.py --symbol ETHUSDT --interval 240 \
    --category linear --leverage 5 --funding 0.01
```

### Прогон генома из веб-лаборатории (без эволюции)

Экспортируйте особь кнопкой **JSON** в панели «Метрики бэктеста», затем:

```bash
python ga_bybit_trader.py --symbol ETHUSDT --interval 60 \
    --import-params quantevo_genome_ETHUSDT_60.json
```

## Вкладка «Торговля · Live» — как пользоваться

1. Откройте вкладку **Торговля · Live** в шапке. Пара и таймфрейм наследуются из лаборатории (меняются в панели настроек);
2. Выберите источник генома: **фиксированные параметры** (ручная настройка) или **лучший геном GA** (появляется после эволюции);
3. Укажите **начальный депозит** (USDT) и **риск на сделку** — размер позиции считается от SL;
4. **PAPER** — виртуальный счёт на реальных котировках, работает без ключей. Нажмите **Старт** — и следите за сигналами, SL/TP на графике и журналом;
5. **LIVE** — вставьте API Key/Secret, нажмите «Проверить соединение», снимите блокировку MAINNET (по умолчанию включён **Testnet**!) и запустите. Рыночные ордера отправляются через Bybit V5, на перпетуале дополнительно выставляются серверные условные TP/SL.

> 🔑 Ключи подписывают запросы **локально в браузере** (HMAC-SHA256, Web Crypto) и отправляются только на `api.bybit.com` / `api-testnet.bybit.com`. Они не логируются и не покидают ваш компьютер. Для тестов создавайте ключи на [testnet.bybit.com](https://testnet.bybit.com).

### Создание API-ключа Bybit

1. Войдите в аккаунт → **API Management → Create New Key**;
2. Разрешения: **Contract → Order** (для perp) или **Spot → Trade** (для спота); чтение баланса включено по умолчанию;
3. **Обязательно** привяжите IP-адрес машины (whitelist) — ключ без ограничений использовать нельзя;
4. Для экспериментов используйте [Testnet](https://testnet.bybit.com) — там отдельные ключи и виртуальные средства.

## Стратегия FibDiv — как это работает

На каждом закрытом баре вычисляется сигнал:

1. **Метод Такенса + EKF.** Лог-цена раскладывается в delay-векторы `(x_t, x_{t−τ}, …, x_{t−(m−1)τ})`; PCA (степенная итерация) выделяет главную компоненту фазовой траектории; расширенный фильтр Калмана (состояние `[уровень, скорость]`, нелинейное наблюдение `h(x)=x₀+0.1·tanh(x₁)`) сглаживает её. Нормированный z-score скорости = **Такенс-импульс**.
2. **Фибо-зона.** По последним свинг-пивотам строится плечо L→H; зона ретрейсмента `[H − fibHi·(H−L), H − fibLo·(H−L)]` активна `life` баров после подтверждения вершины (для long; short — зеркально).
3. **RSI-дивергенция.** Бычья: цена ниже предыдущего свинг-лоя при более высоком RSI (и наоборот). Флаг живёт окно `divLookback` баров.
4. **Фильтры.** Импульс выше порога, RSI не в противоположной зоне, EMA fast > EMA slow (трендовый фильтр).
5. **Исполнение.** Вход по open следующего бара (без look-ahead), TP/SL проверяются внутри бара, реверс-выход по противоположному сигналу, экстремальный RSI-выход.

### Геном (15 генов)

| Ген | Диапазон | Ген | Диапазон |
|---|---|---|---|
| RSI период | 6–36 | Окно дивергенции | 10–90 |
| RSI перепроданность | 15–42 | Плечо свинга | 3–14 |
| RSI перекупленность | 58–85 | Фибо-зона от | 0.20–0.50 |
| EMA быстрая | 8–60 | Фибо-зона до | 0.55–0.85 |
| EMA медленная | 70–260 | Тейк-профит | 0.6–9 % |
| Такенс τ (лаг) | 1–12 | Стоп-лосс | 0.4–7 % |
| Такенс m (размерность) | 2–6 | EKF шум Q | 1e-5–3e-2 (log) |
| Порог импульса | 0–1.6 | | |

Фитнес: `w₁·Sharpe + w₂·ln(PF) + w₃·Ret − w₄·MaxDD·10 + 0.5·lg(сделки+1)`, штраф при числе сделок ниже порога.

```json

  "app": "QuantEvo Lab",
  "version": 1,
  "pair": "ETHUSDT",
  "timeframeMin": 60,
  "market": "spot",
  "leverage": 1,

    "rsiPeriod": 14, "rsiLow": 28, "rsiHigh": 71,
    "emaFast": 21, "emaSlow": 110,
    "takensDelay": 4, "takensDim": 3, "kalmanQ": 0.0021,
    "momThr": 0.42, "divLookback": 34, "swingLen": 6,
    "fibLo": 0.382, "fibHi": 0.618,
```

## Troubleshooting

| Проблема | Решение |
|---|---|
| «СИНТЕТИКА» вместо «BYBIT API» | Bybit блокирует запросы из браузера (CORS/гео). Бэктест работает на синтетике; для реальных данных используйте Python-скрипт |
| 403 при проверке ключей | Проверьте IP-whitelist, права ключа (Order) и выбор testnet/mainnet |
| `10004 sign error` | Неверный secret или рассинхрон часов (> 5 мин) — включите NTP |
| Мало сделок на 4Ч/1Д | Уменьшите «Мин. сделок» в фитнес-весах или расширьте Фибо-зону |
| Ликвидации в бэктесте | Снизьте плечо или расширьте SL — при ×20 ликвидация наступает уже при −4.5% движения |
| GitHub Pages: белый экран | Убедитесь, что сборка шла с `--base=./` (workflow делает это автоматически) |

## Безопасность

- Приватные ключи используются **только** для HMAC-подписи в браузере/Python и отправляются лишь на официальные домены Bybit;
- включайте **IP-whitelist** и начинайте с **Testnet**;
- не храните `.env` и экспортированные геномы с ключами в публичных репозиториях (`.gitignore` уже настроен).

## Дисклеймер

Проект — исследовательский инструмент. Бэктест не гарантирует доходности, прошлые результаты не воспроизводятся в будущем, live-торговля сопряжена с риском полной потери средств. Не является инвестиционной рекомендацией.
